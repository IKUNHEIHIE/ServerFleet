# 更新私有暂存接线候选

updates.ArtifactStager将受签名/固定平台/版本/单调序列/长度/哈希约束的工件流写入受控私有目录。随机目录O_EXCL文件、os.Root限制、Linux目录0700/文件0600；只读公开发布物，未使用真实发布私钥。边下载边有界校验，再fsync并通过同一文件描述符重读复验，不凭下载成功显示可安装。

StagedArtifact不导出路径/写者。WithVerified必须注入当前可信ReleasePolicy与唯一任务read-only gate，先用相同FD复验签名/平台/当前最低序列，再将限长只读流借给程序注册安装器，完整消费后复验和gate。一次对象只准入一次；回调失败/恐慌/取消/读取不足/调用后变更均ErrApplyUnknown，拒绝自动再借用。实际跨进程执行防重放仍由唯一tasks持久executionId负责，本对象的内存fence不宣称跨重启保证。

安装器需用所借流写私有新slot、复验目的文件、在明确授权下切换并报告真实新进程/版本/存储兼容性health。当前组件只暂存和校验，没有把回调nil/health bool当安装成功，没有覆盖当前程序/数据库，没有降级绕签名/任意Shell/包URL执行。原始UPDATE缺失，签名治理、健康协议、不可逆迁移、回退和实际Linux服务安装仍需新决策/统一任务接线。

测试使用真实临时文件覆盖错误/不完整下载、落盘后篡改、当前序列推进拒绝旧包、缺gate拒绝、一次借用与UNKNOWN不重跑、清理仅移除自己随机目录里的固定文件。Linux才目录Sync，Windows仅逻辑文件证据，不能声称断电持久性/双架构安装通过。无新增第三方或公共配置，源io.Reader和安装器必须响应ctx；不能宣称可取消不合作的底层Reader。
