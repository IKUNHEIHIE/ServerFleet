# 合并检查清单

- [ ] 任务编号/唯一会话、基线、分支、目录、允许路径和审查人已登记。
- [ ] 只修改授权范围；无他人数据覆盖；共享文件变更单独协调。
- [ ] 需求/有效 ADR 已核对，无安全边界改变；有冲突已登记。
- [ ] 公共端口、OpenAPI/Proto、数据库公共模型变更列明兼容影响与迁移。
- [ ] `npm ci` 和固定工具安装可重复；锁文件与工具版本同步。
- [ ] Go 格式、编译、单测、vet/staticcheck、架构边界通过。
- [ ] Web 类型、组件测试、构建通过；测试 mock 无生产导入、无真实网络。
- [ ] OpenAPI parse/lint/ref/operationId/路径参数检查通过。
- [ ] Buf lint/format/build/generate/breaking、生成代码一致和往返/拒绝用例通过。
- [ ] 至少一个失败用例；权限相关改动包含撤权/重放/越权测试。
- [ ] 基础依赖扫描通过；风险接受必须明确记录，不能静默降级门槛。
- [ ] 未提交密钥/真实节点数据；可选插件未编入核心；无旁路执行通道。
- [ ] 审查人确认；集成目录全量检查通过后合入 main。
- [ ] 区分本地 PASS、CI 配置存在、GitHub 实际执行三种状态。
- [ ] main 干净，提交可追踪，任务标为已合并；Worktree 内容确认后清理。

本地检查入口：`npm run check`；依赖扫描：`npm run check:security`。报告在各 Worktree 的 `reports/`，失败时先看对应日志。线上 CI 未运行时不能勾选“GitHub 已通过”。
