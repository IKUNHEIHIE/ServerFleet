# 集成检查清单

先核对 [当前状态](CURRENT-STATE.md)和任务范围。按影响选择验证，未运行不能写成通过。

## 所有任务

- 远程 main/任务分支/最终 head 明确，无他人改动混入。
- diff 与授权范围相符；当前功能/API/目录入口同步，历史证据保留。
- PR 说明最终问题/行为、验证和剩余边界；不把同账号 COMMENT 称为独立 APPROVE。
- 集成负责人在审查完成后用 expected head 正常合并，不直接推 main、不强推或绕过保护。
- 结果补 PR 评论；需要轮询时十分钟一次，不为记绿灯反复编辑说明。
- 更新任务板和 CURRENT-STATE；文档提交不算运行验收。

## 纯文档

- 仅 Markdown/AGENTS，无代码、脚本、配置、锁、SQL、生成物、tag 或 Release 改动。
- 相对链接存在；当前版本/工具/迁移/状态能从源码或精确发布回执核对。
- 原始资料、候选、批准 ADR、旧审查/任务/失败/SKIP 不被全局替换。
- git diff --check；记录实际文档检查结果。
- 按用户要求不运行完整 CI，提交与实际合并标题带 [skip ci]；若保护阻止，不能绕过或冒称通过。

## 代码、契约或运行配置

- 按 [工具链](TOOLCHAIN.md)执行必要检查及完整接收检查，最终 head 变化后重审受影响差异。
- 公共接口核对 DTO/处理器、增量候选、生成/索引、前端兼容、权限/审批/UNKNOWN。
- 迁移只追加，旧 SQL/checksum 不变；生产不导入 mock/fixture/可选业务插件。
- 针对变更验证有效负向与边界，不写镜像实现的无意义测试，不每改一处就重复整套检查。
- FAIL/BLOCKED/UNTESTED 和环境 SKIP 如实记录；实机供应商/Root/fence/物理 ARM/资源限额单独验收，CI 不替代。
