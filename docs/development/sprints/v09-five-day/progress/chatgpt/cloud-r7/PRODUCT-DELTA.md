# 本连续编码包的正式界面变化

V09-CLOUD-CODE-COMPLETE-01；本表为实现登记，全部 UNTESTED，用户要求整包代码完成后集中验收。产品、接口与界面同步见 R17/R18/R19；原始需求与历史 ADR 不改。

| 类型 | 界面 | 当前写入行为 | 成功边界 |
|---|---|---|---|
| 新增 | 证书：公开签发 | 从已完成的节点 CSR 和已同步 Zone 登记人工审批签发任务；读取公开链/到期/清理观察 | 签发不代表安装或 HTTPS 健康，网站私钥不进入 Controller |
| 修改 | DNS：账号 | 明确填写已保存的加密 Cloudflare 凭据 ID | 账号引用不等于已验证有效；不把 Token 明文当引用 |
| 修改 | DNS：检查/导入 | 统一 Controller 任务，按现有供应商 Zone ID 导入 | 任务登记不是供应商验证完成，不远端创建 Zone |
| 修改 | DNS：记录新增/修改/删除 | 修改类人工审批任务；冻结待写内容与原记录快照，展示 task ID | 执行前记录未变化；UNKNOWN 不自动重放 |
| 新增 | 发布：DNS 观察 | 公开 batch、执行/补偿 task ID、逐记录复用/创建/删除/未知状态，手动刷新与审批入口 | 队列/202 不是 DNS 已生效；逐步观察同一任务 |
| 新增 | 发布：逆序补偿 | 补偿已执行阶段，DNS 独立人工审批，只处理本次实际创建记录 | 原有记录保留，未知/失败即停，TTL 不代表即时全网回滚 |

未关闭：自动续签、完整远程更新批次、真实旧主控隔离与新权威激活、备份异地与保留、Agent 执行跨重启续传、可选 Runtime 正式准入、物理/ARM/硬 1C1G/真实外部，以及 G2/完整发布验收。代码分支不替代 main 接收、编译或测试证据。

五项核心优先包 R20（UNTESTED）：任务页新增受控程序 profile 表单（节点、公开策略 SHA、argv、超时、普通/受控提权），两者均人工审批；无浏览器可选程序路径/环境/密码，任意程序输出不进入日志。Root 缺 root-owned helper 精确安装/授权时拒绝，不能把 Agent 整体运行成 root 替代。其他四项核心能力继续实现，尚不标整包完成。

R21（UNTESTED）：正式文件页增加“Agent 执行恢复”：按历史任务查看可核验部分，重新审批建立新恢复任务；仅恢复未发布的已确认前缀。旧任务 UNKNOWN/canceled 不改成功；缺源缓存、最终写入状态不明、撤权或 Agent 证明不匹配均拒绝。

R22（代码中，UNTESTED）：系统更新页新增远程 Agent 灰度批次和受监督 Controller 自更新表单；只填版本/已有 Key ID/公开摘要/节点，不能从网页填可执行路径/来源/环境。实际更新需要独立真人管理员审批。Controller 原任务 UNKNOWN 和监督进程历史安装回执分开展示，不把下载、202 或历史健康当成当前活跃健康。
