## AI 运维体验增量（2026-11-17，源码已实现，未部署）

聊天与执行互通当前资源范围内的历史记忆；压缩保留完整用户约束并拒绝静默截断。
输入区可选每段步数/期限，明确的步数停止点支持人工续接；未知操作仍先核对。
模型可以显式检测工具调用与公开摘要能力，检测不操作节点。
对话过程提供可折叠工具参数、回执与简要思考摘要，普通回复支持真实增量预览，
只有服务端确认完成后才作为最终消息。[详情与限制](../development/AI-AGENT-LOOP.md)。

## 节点管理体验补丁（2026-11-15，工作区待提交）

节点列表支持点击名称进入详情；每行最右侧的更多菜单提供编辑与删除快捷操作。编辑名称与资产资料，删除只需勾选确认、不再要求填写原因（审计记为“未填写原因”）。删除会撤销接入并从普通列表移除，保留历史审计和关联记录；不声称远程 Agent 已卸载。编辑、暂停、删除分别需要 nodes.write、nodes.suspend、nodes.revoke 的明确节点授权。管理员可在详情页为当前账户明确授予单节点管理权限，授权成功后立即刷新资源。

节点列表、详情与诊断每 5 秒刷新；刷新失败显示过期提示，失联不推断关机。添加节点改为“命名与接入凭证 / 可信安装 / 接入审批”三段，节点名称与安装命令一致；默认名称随机可区分。移除原安装审批长说明及契约缺口占位文案，保留令牌、Root pin 和发行验签校验。安装命令默认改为从面板下载并核对摘要的短命令；脚本创建专用用户与 systemd 服务并启用文件能力（非 root 运行 + `-file-root`）。节点详情不再展示账户级节点管理授权与协议/能力清单，改为展示 CPU 型号/核数、内存、存储与本月流量；系统设置的凭据类型直接列在凭据页内。文件互传页的传输历史收进页头按钮弹窗；监控资源与节点列表同频刷新并展示采样时间。

分组页增加“一键分类”，重新读取当前地区、云厂商或标签维度并重置失效筛选和分页；分类只基于可见节点，不写入手动分组或扩大资源授权。

## 常用操作

1. 按[部署说明](../../deployment/README.md)构建或使用可信发行包，配置同源 HTTPS、内部身份信任、数据库/暂存私有目录并初始化管理员。
2. 在资源授权中明确分配节点操作；添加节点时使用[一键安装](../../deployment/INSTALL.md)，核对外部可信公钥和 Root pin，观察真实在线及能力。
3. 执行前先预览目标与变更范围；审批通过后看任务及子执行回执。界面显示“已提交”只表示请求/任务已接受。
4. 源故障、网络中断或结果不明时进入[人工处置](../development/INCIDENT-CLOSURE.md)；使用新任务明确核验或修复，保留旧事实。
