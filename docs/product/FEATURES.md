## 功能与实现状态

| 功能 | 当前提供 | 使用条件与剩余边界 |
|---|---|---|
| 登录与用户权限 | 首次管理员初始化、Cookie 会话、用户/角色/资源授权、会话撤销、凭据元数据 | 直接 HTTPS、精确 Origin、写入 CSRF；管理员也需相应节点资源授权。未提供 MFA 实现，启动要求第二因素会拒绝 |
| 添加节点 | 10分钟以内一次性令牌、自动注册/人工审批、独立身份签发、吊销/重装 | 可信安装目录、外部核对签名公钥和 Root pin、Agent 能力及 mTLS；每节点独立私钥 |
| 节点与分组 | 节点状态、基础资源/网络采样、地区/标签及普通分组管理 | 未上报数据保持未知。普通分类分组与服务组语义独立 |
| 服务组 | 成员、暂停、策略、当前成员修订和引用检查 | 批量任务/发布等冻结成员快照，不能将后加入节点悄悄加入旧授权 |
| 任务与审批 | 预览、节点/组目标、分批执行、审批、取消、事件/日志和终态对账 | 当前目标/操作授权持续检查；修改/root 保留独立真人审批；离线TTL与并发有界 |
| 文件互传 | 上传、下载、跨节点、多目标，skip/overwrite/rename，摘要/真实路径回执 | 配置受控文件根与执行通道；确认前缀后显式续传，新任务重新审批；最终发布未知时不重放 |
| 网关管理 | 在线节点 Nginx 安装/纳管、调度暂停、路由、健康及逆序补偿 | 配置可信工件、节点执行根及当前授权；暂停调度不等于停 Nginx；真实站点联调待用户完成 |
| 服务发布 | 服务组/网关/DNS/证书预览、冻结发布计划、阶段任务、健康检查和补偿 | DNS/ACME/网关执行配置须齐全；部分成功和 UNKNOWN 均保留历史；取消不等于回滚 |
| DNS 管理 | Cloudflare 账号/凭据引用、Zone、记录、默认账号、统一执行任务 | 首版仅 Cloudflare；服务端固定供应商边界，凭据受控借用。真实账号联调仍待完成 |
| 证书 | ACME、公网/内部信任、节点 CSR、独立签发、安装链、服务组分发 | 离线 Root 不在线自动化；公私钥不能跨节点共享；需配置内部 PKI/供应商 |
| 自动续签及发布 | 续签策略、安装后继、发布替换、检查/回执与人工修复采用 | 修改任务和独立审批继续有效；旧 UNKNOWN 不重跑；真实证书/服务重载待联调 |
| AI 运维 | 会话资源范围、三种审批模式、受控工具、多轮 Agent 运行、任务回传、取消/恢复入口 | BYOK/模型配置；代码强制资源边界。完全访问不豁免任意 root 的真人审批；Eino 不作为已准入运行时 |
| 工作流 | 定义/修订、事件匹配、手动触发、步骤任务和运行状态 | 1—32步，每步冻结节点与操作权限；任务/审批是执行权威。没有通用可执行脚本插件；不承诺额外 Cron 定时器 |
| 服务监控 | Controller 或指定节点的 HTTP/TCP/TLS、连续失败/恢复阈值、维护、历史 | 节点来源仅公网、目标≤1024字节、目标超时1—30秒；Controller 目标超时1—300秒，私网须显式白名单 |
| 监控状态 | up/down/unknown观察、当前未知提示、真实 taskId 链接、告警 outbox | 源离线、能力缺失或未知执行不算业务宕机；UNKNOWN打断连续次数；元数据编辑不清除未知事实 |
| 通知 | SMTP 与 QQ 官方 Bot、渠道设置、测试、投递任务/历史/人工处置入口 | submitted/provider_accepted不等于用户已收到；delivery_unknown不自动重发；首版无 Telegram |
| 流量/到期 | Agent 主机网络增量、账期覆盖、配额阈值、到期提醒 | 初次计数、计数重置或跨月缺样不伪造完整月用量；Xray用户级统计仍受插件执行缺口限制 |
| 更新 | 固定可信来源、离线签名、Controller/Agent监督更新、批次和健康回滚 | 需独立 supervisor/owned 进程/可信清单；未知停机/安装不盲目重启。物理ARM与真实提权待验收 |
| 备份与恢复 | 一致性加密备份、S3兼容/WebDAV异地上传和读回验证、保留预览/清理/保护 | 外部加密工具/收件公钥与存储凭据须配置；清理独立审批，保留最小副本/恢复引用 |
| 灾备接管 | 隔离恢复、旧owned进程 fence、新权威/代次、离线Root授权激活 | 不接受自称已隔离；真实双机/旧主控网络隔离与Root操作仍待用户验收 |
| 异常人工处置 | 收件箱、认领、证据/新鲜快照、后续任务、独立复核、依据变化重新核查 | 人工结案不把原 UNKNOWN 改为成功，不复活原审批或重放原执行 |
| 审计 | 持久审计、当前授权读取、筛选和保留 | 日志/回执不输出 CA/恢复私钥、Token、凭据或原始供应商错误正文 |
| 插件平台/Xray | 包来源/签名/清单/生命周期元数据、声明式页面；Xray业务模型与隔离组件代码 | **未完成生产执行装配**：无已准入 PluginRuntime/XrayTaskHost。安装包不等于可启动；模板校验、安装/发布、用户/流量/导出不能当作完整可用 |
| 受限脚本令牌 | 签发/元数据/撤销、短期限/节点范围/读权限/提交门校验端口 | **正式节点/任务HTTP尚未接Bearer读取适配**。不能仅用签发成功证明脚本能访问；不扩大为任意API Token |

## 常用操作

1. 按[部署说明](../../deployment/README.md)构建或使用可信发行包，配置同源 HTTPS、内部身份信任、数据库/暂存私有目录并初始化管理员。
2. 在资源授权中明确分配节点操作；添加节点时使用[一键安装](../../deployment/INSTALL.md)，核对外部可信公钥和 Root pin，观察真实在线及能力。
3. 执行前先预览目标与变更范围；审批通过后看任务及子执行回执。界面显示“已提交”只表示请求/任务已接受。
4. 源故障、网络中断或结果不明时进入[人工处置](../development/INCIDENT-CLOSURE.md)；使用新任务明确核验或修复，保留旧事实。
