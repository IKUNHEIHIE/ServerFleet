# Server Fleet — 统一交付包（截至 G2）

这是包含 **截至 G2 阶段所有现行开发交付文件** 的单一 ZIP。当前产品版本为 **v0.9**。

## 如何使用

1. **先看 `01-当前开发基线/README-ServerFleet-G2.md` 和 `AGENTS.md`**。
2. `01-当前开发基线` 是唯一用于继续推进 G2 校验和 M0 开发的**现行文件集合**，包含功能需求、Xray 插件、React HTML 交互原型、G1 已批准 ADR、REST API、Agent Protobuf、验收与测试计划。
3. `02-历史交付包` 仅供版本追溯，保留 v0.2–v0.9 的旧快照、G1 提案等；它们的旧规则**不能覆盖当前 G1 已批准决策**。
4. `03-其他审查资料` 为开发前审查报告。
5. G2 OpenAPI 仍标记为 **candidate**，Protobuf/WASM/mTLS/权限 PoC 尚未全部实测通过。**不能把设计文件当作已经开发完成的系统**。

为避免重复，本 ZIP 只保存一份现行文件集，历史版本以原始 ZIP 归档；没有再将现行 G2 包重复嵌套其中。

`SHA256-MANIFEST.json` 可用于校验各个原始文件内容。
