# Server Fleet v0.9 — 变更记录

**日期：2026-10-29**  
**变更类型：用户正式批准的首版可选插件需求；不代表真实后端/插件实现完成。**

## 新增：FR-PLUGIN-XRAY-001

- 第一版唯一已批准的官方可选插件：**Xray 节点管理器**，取代 v0.8 暂无已批准具体插件的状态。
- 插件中心目录新增唯一 Xray 条目，**初始未安装**；仅点击安装模拟后可启用及显示业务入口。原先移除的六个演示插件不恢复。
- Xray 批量安装/更新/启停/节点卸载，已有实例保护、平台/端口/权限预检查，复用主控安全批量任务。
- 版本化配置模板：`VLESS + TLS + Vision`、`VLESS + REALITY + Vision`，以及自定义 Xray JSON；要求目标版本 Xray 配置验证、发布差异、修订、失败恢复。
- Xray 用户管理、凭据引用、客户端连接信息受控导出；流量统计区分节点、入站与用户，记录重启、计数器重置和数据缺口。
- 不与主机网络流量/云厂商账单混淆；插件不获得无限 root、SSH、原始 CA 密钥或访问 AI 未授权节点的能力。

## 文档与 API

- 新增 `Plugin/xray-manager/FR-PLUGIN-XRAY-001.md`，独立现行功能与验收规范。
- 新增 `Plugin/xray-manager/Xray-Manager-OpenAPI.yaml`，插件 REST API 草案：19 路径、23 操作、30 Schema。
- 主 OpenAPI 由原 v0.8 的 100 路径/128 操作/102 Schema，扩展为 119 路径/151 操作/132 Schema；既有接口保留。
- 现行需求规范升级 v0.9，增加 Xray 插件集成章节，其他模块已批准规则保持不变。
- 增加 `Plugin/index.json` 与 `manifest.yaml` **设计占位清单**，状态为 `approved-not-built`，不包含可执行插件/签名发布包；实际官方仓库地址仍待绑定。

## 前端原型

- v0.9 插件目录默认只有 Xray，安装/启用/禁用/卸载为本地模拟。
- 已启用插件入口内展示六个示意子页：概览、Xray 节点、配置管理、用户管理、流量统计、部署记录。
- 新增模拟批量安装、模拟配置发布、模拟用户状态、模拟流量采样及任务记录；不执行真实服务或生成有效连接凭据。
- 原有节点、DNS、文件互传、AI、任务、网关、证书与恢复功能均继续保留。

## 尚未解决、实施前必须完成

- 官方仓库地址、签名制品、插件运行方式及 Agent 白名单动作的正式 ADR 对齐。
- 目标 Xray 版本兼容性矩阵、安全回归测试、REALITY 参数校验和流量采样一致性测试。
- 真实 Controller/Agent 执行器、真正的凭据保护、RBAC/AI 权限负向测试以及真实回滚验证。
