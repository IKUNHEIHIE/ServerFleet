# QA — Server Fleet v0.9

## 已验证

- JavaScript 语法检查通过（Node `--check`）。
- 浏览器在隔离页面以本地 HTML 运行，无控制台页面异常。
- 插件中心仅显示一个 Xray 插件目录项，初始未安装；模拟安装并启用后菜单可见。
- Xray 子页的节点安装、配置发布、用户新增、流量样本和部署记录交互测试通过。
- 本地原型没有实际联网、下载 Xray-core、生成真实 UUID 或真实代理配置。
- 独立插件与主 OpenAPI 可以用 YAML 解析，全部内部 Schema 引用有效，操作 ID 唯一。
- v0.9 新增 19 路径、23 操作；与 v0.8 既有 100 路径无冲突。

## 不能据此验收的事项

- 不能证明真实 Agent 安装、服务安全重载、恢复、插件隔离、Xray StatsService 数据准确性。
- 未实际连接 Cloudflare、Xray、SMTP、QQ 或任何 VPS；前端状态不能代替服务端授权。
- Xray 官方仓库的正式插件发布制品、签名与自动更新尚未建成。
