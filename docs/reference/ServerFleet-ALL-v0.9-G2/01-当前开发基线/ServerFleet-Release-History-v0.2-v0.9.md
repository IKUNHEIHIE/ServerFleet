# Server Fleet — 产品迭代历史（v0.2～v0.7）

**定位：历史追溯，非现行功能规范。** 当前唯一有效的产品需求基线为 `ServerFleet-Functional-Requirements-v0.7.md`。

历史内容中出现的旧文件名、旧页面名或“当前版本”仅反映当时背景；不要据此覆盖 v0.7 的决定。

## v0.2 — 原始变更记录

### v0.2 · 2026-10-28

关联需求：**FR-FT-001**

**新增**
- 「核心功能」新增「文件互传」模块，参照用户提供的宝塔面板图片采用左右对称文件浏览器。
- 允许两侧独立选择节点与路径，面包屑导航、返回、刷新、文件名过滤和分页。
- 支持单项目发送、多选批量发送、确认目标路径、跳过/覆盖/重命名同名文件。
- 增加模拟传输任务列表、状态、进度、详情、取消及操作审计。
- 增加模拟上传、目录创建、大小计算、重命名及删除操作。
- 节点详情增加「文件互传」快捷入口，自动选择当前节点作为左侧来源。
- 用户权限示意矩阵补充文件查看、文件上传与互传、文件删除与覆盖权限。

**同步文档**
- 建立完整产品功能目录和 FR-FT-001 详细功能规则、验收、异常场景。
- 建立 OpenAPI 3.1 草案，包含目录枚举、大小统计、创建目录、重命名、删除、上传会话、异步文件传输与取消任务。
- 明确不跟随符号链接、跨节点源/目标双重授权和审计要求。

**限制/待讨论**
- UI 为纯本地数据模拟；没有真实文件字节传输、后端 API、SSH/SFTP、浏览器下载或断点续传。
- 现有其他功能模块的正式 API 仍待规划。
- 待明确跨节点移动、下载/压缩/解压、在线编辑、速率限制、失败重试、取消后的部分数据处理。
- 既有已批准架构 ADR 未更改。

## v0.3 — 原始变更记录

**日期：2026-10-28**  
**变更：FR-GW-001、FR-DNS-001**

### 已确认

- 「服务入口管理」统一更名为 **网关管理**（应用网关语义），保留既定 4 台 Nginx 网关节点及原有服务路由；不修改获批 ADR。
- 「Cloudflare DNS」更名为 **DNS 管理**，可根据账号/域名选择并隔离 DNS 记录。
- 「系统设置」新增 **DNS 供应商** 页面，第一版仅提供 Cloudflare；支持多个 Cloudflare 账号的模拟新增、编辑、启停、设默认、删除、连接检查说明。
- DNS 管理增加切换账号和域名、添加演示域名、对所选 Zone 的记录新增/修改/删除、模拟同步说明。
- 旧 v0.2 浏览器记录迁移到演示 Cloudflare 账号默认域名；旧侧栏和模块数据保留。
- 原型真实 API Token 字段禁用；没有收集、持久化或展示明文密钥，也不虚构连接成功。

### 文档同步

- 更新产品功能需求文档：FR-GW-001、FR-DNS-001 的产品定位、交互流程、边界条件、验收标准。
- OpenAPI 草案更新至 `0.3.0-draft`：新增 DNS 供应商、账号、Zone、记录和网关路由的拟议资源模型及端点。
- 文件互传 FR-FT-001 原有产品规则及 API 契约完整保留。

### 仍未实现

- 真实 Cloudflare OAuth/API Token 接入、Zone 同步、DNS 解析变更、后端网关路由发布。
- 其他 DNS 供应商不在第一版范围；功能扩展能力存在，不代表已适配。
- 后端的凭证安全存储、账号权限验证、审计能力尚未实现；OpenAPI 仅为提案。

## v0.4 — 原始变更记录

日期：2026-10-28 · 产品原型阶段 · 不含真实后端

### 新增
- 系统设置 → 通知设置：QQ 官方机器人和 SMTP 两类首版渠道；模拟配置、启停、测试、日志、QQ→SMTP 故障备用选项。
- 节点地区国旗展示：节点列表、节点详情、网关节点选择器及网关列表；未识别显示 🌐。
- 网关管理 → **新建网关**：仅在线且未登记的节点可选择；模拟授权、Nginx 安装/检测、失败重试、调度准入、维护模式；只有全部检查通过且在线启用才调度。
- 插件中心 → **仓库配置**：官方仓库（实际 URL 待确定）或开发者 GitHub Fork、分支/Tag、固定 Plugin/ 目录；本地模拟刷新。
- 插件全生命周期：模拟按需安装、权限确认、热启用、热禁用、热更新成功/失败保留旧版、热卸载、动态插件菜单与历史记录。
- ZIP 中包含 `Plugin/` 规范示例与独立 README（不是可执行插件）。

### 调整
- 「接入与审批」→「添加节点」；「节点管理」页面→「节点列表」，与「分组管理」一起作为一级「节点管理」的二级子菜单。
- 「AI 运维助手」→「AI 运维」，迁移至「核心功能」。
- 默认不预装任何可选插件；文件互传和网关等核心能力不依赖插件。
- 原先计划 4 台 Nginx 网关保留为初始目标，网关管理不硬编码数量上限。
- API 文档增加 GatewayProvisioning、PluginRepositories、PluginLifecycle、Notifications 等契约及状态模型。

### 移除
- Telegram 作为第一版通知渠道，不再有可配置的渠道开关。

### 延续
- v0.2 文件互传；v0.3 DNS 管理与多 Cloudflare 账号、证书、任务、工作流、审计、基础监控等原型。

### 安全与限制
- HTML 仅模拟状态，不会访问 GitHub、安装 Nginx、运行插件或发送通知。
- 演示不接受或保存 SMTP 密码、QQ AppSecret；演示填写的非密钥字段存储在浏览器 localStorage。
- v0.3 原型数据沿用同一本地存储键，v0.4 首次使用时补充新字段并重新初始化旧插件示例状态。浏览器中用户已安装的 **演示插件状态**可能重置；不涉及真实服务器。
- 新插件发布与旧 ADR 内置插件条款的冲突需要独立 ADR 修订；本次未改已批准的架构决策记录。

## v0.5 — 原始变更记录

日期：2026-10-28；性质：产品需求 / 交互前端 / OpenAPI 草案迭代，非真实后端发布。

### 新增

- **FR-UPDATE-005**：系统设置新增「系统更新」入口、检查更新、一键更新、模拟成功与失败恢复、更新记录；原更新中心共享同一模拟状态。
- **FR-SERVICEGROUP-005**：核心功能新增「服务组管理」，支持创建、编辑、删除、成员管理、启停负载均衡、关联网关、暂停单节点参与调度；服务组与标签式节点分组区分。
- **FR-CERT-005**：证书管理新增「内部 TLS 与下发」标签，支持选择服务组、CA 信任包或逐节点身份签发、逐节点状态、模拟撤销；不共享私钥。
- **FR-AI-SCOPE-005**：AI 运维页顶部节点/服务组资源块，拖拽或点击添加到会话授权区、授权撤回、零授权新会话、资源推荐与人工审批；服务组成员快照，避免自动扩权；计划授权版本二次检查。

### 接口新增

- `/api/v1/system/update-*`：版本检查、更新计划、安装、作业查询、可行的恢复。
- `/api/v1/service-groups` 及成员、网关绑定、候选后端等接口。
- `/api/v1/certificates/internal/*`：内部证书签发/下发任务、状态、撤销和轮换。
- `/api/v1/ai/sessions/*`：创建会话、资源授权/撤回、只读作用域、资源申请/审批、受控工具调用及执行计划审批。

### 保留与兼容

- 完整继承 v0.4 的基础功能：节点、文件互传、DNS、QQ Bot/SMTP、网关准入、按需插件仓库及插件热管理。
- v0.5 沿用浏览器本地演示数据键，增加一次性字段迁移；不对 v0.4 历史字段做破坏性重命名。
- 页面和接口均为原型草案；不存在真实的自动升级、TLS 下发或后端 AI 授权执行。

### 需要在正式研发时验证

1. 更新/回滚过程面对不可逆数据迁移、控制器重启和故障恢复的语义。
2. 服务组健康检查与网关路由联动；有成员变更时防止失控扩大 AI 授权。
3. 私有 CA 身份证书的密钥生成、撤销、轮换、信任传播。
4. **AI 后端强制授权**：唯一受控工具网关、提交/执行时双重检查、凭据/网络横向访问隔离、审计、异步撤权和跨工具测试。

## v0.6 — 原始变更记录

日期：2026-10-28
状态：纯前端交互演示 + 功能需求与后端契约草案

### 新增

- AI 运维顶部新增「每次审批 / 自动审批 / 完全访问」三种卡片式会话审批模式。
- 每次审批为默认模式，工具查询和修改操作都需要用户逐次批准。
- 自动审批：只读和服务端白名单内低风险操作可自动运行，其余等待审批。
- 完全访问：确认风险后可选择 15/30/60 分钟限时自动审批，过期自动恢复为每次审批。
- 审批事件历史：显示模式变化、等待审批、自动允许、人工批准和拒绝。
- OpenAPI 新增读取/修改审批模式、创建审批请求、处理批准/拒绝和读取审批审计事件 4 个路径。

### 保留

- v0.5 所有节点/服务组拖拽授权、快照冻结、后端强制隔离、撤权、资源推荐及其他全部业务页面保持不变。
- **任何模式下未授权资源不可访问**，完全访问不能绕过用户权限、组织禁令、受控工具执行器。
- 新对话恢复零资源授权和每次审批。

### 仅为模拟

原型中的权限与审批拦截使用浏览器状态演示，并不是安全证明；正式系统必须按 v0.6 API 契约在服务端校验，保留全量审计及跨节点凭据隔离。

## v0.7 — 原始变更记录

日期：2026-10-28  
状态：功能需求 + HTML 交互演示 + OpenAPI 契约（未实现后端）

### 分组管理体验重构（已批准）

- 页面改为「自定义分组 / 自动分类」双视图。自动分类按地区、云厂商和标签切换，结果直接显示在右侧统一节点表格，不再打开分类弹窗。
- 自定义分组仍支持新建、编辑、删除及跨组成员关系；右侧提供节点名/IP/标签搜索和在线状态筛选。
- 新增侧边抽屉管理分组成员：搜索、地区/厂商/状态过滤、单选/批量勾选、当前筛选全选/取消、保存或放弃变更。
- 统一节点表格列：名称/IP、地区国旗、云厂商、状态、CPU、内存以及操作。
- 保留原有 localStorage 演示数据与分组 ID，避免重置用户模拟内容。

### API 契约同步

- NodeGroups 增加自定义分组增删改、原子成员替换、自动分类维度查询和统一分组节点结果。
- 明确用户可见范围过滤、成员权限校验、乐观并发版本与操作审计。
- 声明 NodeGroups 与 ServiceGroups 不可混为一类资源。

### 保留 / 非目标

- 完整保留 v0.6 的 AI 三级审批与会话资源授权、插件热管理、DNS、证书、文件互传、服务组、网关、通知和更新。
- 不新增真实后端；分类与分组更新均为浏览器本地模拟。
