## 证据记录单（每个 PoC 一份）

- Git commit / 软件依赖版本 / OS / CPU 架构 / CPU&RAM / 运行时间
- 验证目标 / 正常流程 / 负向流程 / 真实命令及可复现步骤
- P50/P95 或可测时延、RSS/CPU、磁盘与网络占用；不可测项说明
- 失败事件、状态恢复结果、日志保留位置与安全脱敏记录
- **结果：PASS / FAIL / BLOCKED（禁止空白默认为 PASS）**
- 对应 ADR 条款、是否允许进入 G2 冻结/相应 Mx 开发

## 失败处理

WASM PoC 失败：不自动转向第三方进程插件，须提交经用户批准的替代 ADR。Xray 不支持某平台/配置：缩小官方受支持版本/平台并记录产品差异，不放弃预检。权限负向测试 FAIL：停止对应模块安全冻结；任何“能用”演示都不代表通过。
