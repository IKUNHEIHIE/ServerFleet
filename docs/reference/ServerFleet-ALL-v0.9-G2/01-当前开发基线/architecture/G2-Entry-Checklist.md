# G2 接口与通信协议设计启动清单

**状态：允许启动接口设计；不能宣称 G2 已通过。** 产品规范与已批准 ADR 是上游。现有主 OpenAPI（119 路径、151 操作）及 Xray 独立 OpenAPI（19 路径、23 操作）属于**设计草案**，不得未经评审直接用来生成最终正式服务端。

## 必须统一的契约

1. **版本与错误**：API 版本、统一错误对象、HTTP 状态、字段校验、分页/排序/过滤、服务器端 idempotency key、ETag/revision、时间与单位约定；禁止机密字段回显。
2. **权限**：登录/会话、RBAC、节点范围/服务组快照、审批票据一次性、插件 host capability、AI 会话 scopeRevision、审计事件；用后端负向测试证明不可越权。
3. **任务唯一来源**：规范化 `/tasks` 与旧 `/jobs` 的映射，只允许一套实际调度资源；锁定创建、目标快照、审批、取消、暂停/恢复、TTL、逐节点 executionId、Unknown 结果、SSE 日志游标语义。
4. **Agent Protobuf**：注册/接入、双向 mTLS 长连、心跳、指标、版本/能力协商、Offer/ACK/Started/Output/Finished/Cancel/Sync、重连去重、流量限速；文件传输单独确定流式路径，不直接混入日志 SSE。
5. **插件契约**：manifest、签名/摘要/权限授予、UI Schema、Host API 版本、权限与限额、安装/启停/卸载状态机、错误原因、在途任务处理、版本回退；明确 WASM 尚有未解决 PoC。
6. **网关**：发现/接管和全新安装作为不同的受控计划，Nginx 受管文件归属、服务健康、调度准入独立标志。
7. **Xray**：节点安装预检、模板版本、REALITY/TLS 密钥引用、用户/入站身份、独立代理流量计数、重启/采样缺口、配置测试与部署回退；禁止 API 直接回传长期密钥原文。
8. **灾备**：在线一致备份、加密材料、恢复隔离态、过期任务失效、Root 信任连续性、不让旧备份复活已吊销身份。

## G2 验收

- OpenAPI 3.1 可解析，引用/operationId 唯一，路径参数、请求响应/错误示例、鉴权声明完整。
- Protobuf `buf lint` 或等价规则通过，生成 Go/TypeScript 兼容性验证与破坏性变更检查。
- 每个高风险异步动作存在可执行的状态机与可证明的授权/幂等负向用例。
- 插件 PoC/平台假设与接口冻结一致；若 PoC 尚未完成，相应接口只能冻结不依赖运行时的核心部分。
- 所有变更都必须在新 G2 变更记录中列出，不能把未定技术写成“已生产实现”。

先冻结“认证与权限 + 节点身份/通信 + 任务执行 + 审计”四个基础契约，再冻结插件/Nginx/Xray 等依赖性较高的业务扩展；产品原型和既有正式功能清单不需要再调整。
