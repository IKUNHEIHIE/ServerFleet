## 统一审查顺序

1. 先评审 **PLUGIN** 机制，否则唯一插件无法按需安装、热更新；不得按旧 D2 直接编译进主控。
2. 再评审 **DEPLOY** 新建网关路径，确认不影响已有 Nginx 网站。
3. 确认 **AI/PRIV** 不可绕过的审批和权限交集，并连同 Xray 的最小能力映射进入安全测试。
4. 核对 PKI/TASK/WC 等无冲突条款沿用，必要时仅新增注释而不重新进行无意义选型。

**通过标准：** 每项被正式批准的修订 ADR 标明取代了哪一段旧决策、为何改变、兼容/迁移路径、失败处理与验证证据；旧文档归档可查。此登记表本身不具有替代效力。
