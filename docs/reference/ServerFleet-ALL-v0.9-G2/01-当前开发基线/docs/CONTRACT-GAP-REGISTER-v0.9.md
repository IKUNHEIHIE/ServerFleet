# OpenAPI / 通信契约缺口登记（v0.9 只读审查）

**基线：** 主 OpenAPI v0.9 = 119 路径 / 151 操作 / 132 schemas；Xray 独立契约 = 19 路径 / 23 操作 / 30 schemas。**本次没有修改任何既有 API 路径、operationId、请求/响应和 Schema。** YAML 结构有效不等于实现可直接生成完整联调代码。

| ID | 风险区域 | 需补充或确认 | 影响 | 下一阶段 |
|---|---|---|---|---|
| API-G01 | 登录与身份 | 会话/登录、登出、会话失效、认证错误，管理员初始化 | 没法完成安全登录闭环 | G2 |
| API-G02 | 用户角色和资源范围 | 用户/角色 CRUD、权限枚举、逐节点/服务组作用域、审计拒绝 | 不能安全分工 | G2 |
| API-G03 | 审计检索 | 审计分页/过滤、敏感字段脱敏、拒绝事件不可篡改语义 | 无法核实操作 | G2 |
| API-G04 | 节点完整生命周期 | 列表之外的详情、资产修改、停用/移除、身份吊销/轮换、功能协商 | 接入后难维护 | G2 |
| API-G05 | 任务与事件 | 确定唯一 `/tasks`/`/jobs` 命名；任务列表、取消、继续、逐节点执行结果、SSE 事件流、重连游标 | 多 Agent 重复造任务系统 | G2 |
| API-G06 | AI 消息 | 消息流、工具活动事件、历史及错误恢复；会话资源授权和审批策略绑定 | AI 页面无法完整交互 | G2 |
| API-G07 | 公网 TLS 与备份 | 公开证书管理全生命周期、备份记录/下载/恢复只读预览及加密信息边界 | 页面闭环不完整 | G2 |
| API-G08 | 通用插件协议 | 清单签名、UI Schema、插件数据源/动作登记、热生命周期和兼容协议、权限拒绝 | Xray 不可安全独立安装 | G1/G2 |
| API-G09 | Agent 传输 | **单独** Protobuf/mTLS 注册、能力协商、TaskOffer/Ack/Result、取消与幂等协议 | REST 不能替代通信层 | G2 |
| API-G10 | 统一返回约定 | 400/401/403/404/409/412/429/503、分页、幂等、修订号、任务拒绝码 | SDK/前端实现不一致 | G2 |
| API-G11 | 跨模块权限 | 服务发布需同时授权服务组/网关/DNS Zone/证书；Xray 节点权限不能隐含全局凭据权限 | 间接越权风险 | G2 |
| API-G12 | 安全测试数据 | 请求/响应样例，超时/重复提交/撤权/部分失败/插件禁用的契约负向用例 | 只测 YAML 不够 | G2 |

## 已排除的假阳性

- 通过共享 `$ref` 引用参数后，当前 119 条路径并未出现审查报告最初怀疑的“全部路径变量缺失”问题；不能未经验证以此为由重写 API。
- Xray 插件 API 已合并到主契约，但其存在不代表通用插件 SDK/运行时协议已经定义完毕。

## 处理规则

- 每个缺口先确认为独立 API 变更提案，再修改主/插件 Schema 和样例测试，合并时保留可追溯版本历史。
- 该清单只是开发准入风险登记，**不是**对新增业务需求的批准，也不要求本次 docs-r2 直接创造未经讨论的字段。
