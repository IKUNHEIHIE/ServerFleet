## 统一验收定义

- **当前状态：** 需求已批准，在线/离线 HTML 原型提供部分流程演示，真实后端测试均未完成。
- **开发完成：** 不以页面“按钮可点”为判定；必须具备实际后端权限校验、正常执行结果、失败与撤权/越权负向测试。
- **交付证据：** 版本/commit、测试报告、目标环境、日志摘要（不含秘密）、必要的性能采样。必须区分单模块单测、模拟集成与真实 Linux 节点端到端。
