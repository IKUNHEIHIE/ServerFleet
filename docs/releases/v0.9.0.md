# Server Fleet v0.9.0 · 首个正式版

本次提供 Linux amd64 / arm64 预编译核心包，各包含 Controller、Agent、React Web、配置示例和部署文档；可选 Xray 插件不随核心打包。

## 下载与核对

- Intel / AMD 64 位服务器选择 `serverfleet_0.9.0_linux_amd64.tar.gz`。
- ARM 64 位服务器选择 `serverfleet_0.9.0_linux_arm64.tar.gz`。
- 下载对应压缩包和 `SHA256SUMS`，在下载目录执行 `sha256sum --ignore-missing --check SHA256SUMS`，确认对应文件为 `OK` 后解压。
- `build-manifest.json` 记录完整构建的精确源码提交、固定工具版本及文件摘要；各包的 `release-info.json` 记录本架构内容。

解压后先阅读 `deployment/README.md`，按说明初始化 HTTPS、内部 PKI、运行目录与管理员；Controller 的 Web 目录配置指向包内 `web/`。程序面向 Linux；交叉编译不等于 ARM 实机联调通过。

## 签名与安装边界

**本次预编译包未做离线发行签名。** SHA-256 可核对下载内容，不能代替独立核验的发行签名。包内签名输入 manifest 仍是 unsigned；已有一键安装及自动更新要求签名的安装目录/组件清单，本次下载包不能直接作为它们的受信任更新源。需要使用该流程的管理员须按部署文档完成离线签名并独立分发受信任公钥，不得跳过验签。

发行流程在固定源码提交上使用 Go 1.27.4、Node 24.22.1 和 npm 11 构建；包内不含运行数据库、CA/发行私钥、Token、用户凭据或可选插件执行程序。

## 本版范围

核心包括节点/服务组、统一任务与审批审计、文件互传、网关与发布、DNS/证书续签编排、AI 运维执行循环、监控与通知、流量配额、更新/灾备、异地备份与保留清理、异常/UNKNOWN 人工处置。详细配置前提以仓库 `docs/product/FEATURES.md` 和 `docs/api/README.md` 为准。

已知限制：Xray 生产 Runtime/Host 执行装配未完成；受限只读令牌的正式节点/任务 HTTP Bearer 适配未装配；真实供应商、root/监督进程、双机灾备、物理 ARM 与硬限制 1C1G 仍需用户实机验证，完整 G2 验收尚未关闭。前端 UI 后续单独重构。
