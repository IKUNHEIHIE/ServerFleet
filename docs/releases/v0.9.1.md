# Server Fleet v0.9.1 · 身份续期与运维修复

本版修复 Agent 身份证书缺少自动续期的问题：常驻 Agent 在到期前请求当前身份约束的幂等续签，验证并原子保存后等待执行结束、切换连接；新身份真实使用后才退役旧证书。短寿命、撤销、mTLS、Root pin、信任代次及 UNKNOWN 不重放约束继续有效。

- 添加节点批准对话框新增明确的当前账户读取授权选项；仅授予单节点 nodes.read。
- 已核验的过期身份可由具有该节点 nodes.revoke 权限的管理员签发替换令牌，保留节点 ID 和执行账本，重新审批后吊销旧证书。
- 新增只读 `controller upgrade-check`，启动在迁移前校验旧身份/原 keyring，并给出固定错误分类。
- 新增 `/readyz`、关联请求 ID 的脱敏访问日志、Host/Origin 固定诊断码。
- 节点诊断记录最新版本/能力/证书期限及每节点最多 100 条连接事件，增加到期提示。
- 包含升级、身份恢复、TLS 反代与 token-file 权限示例；原49项迁移保持，新增诊断迁移为第50项。

**升级先停止旧写入并备份 DB、原 credential-keys、PKI、配置和执行账本，先运行包内 deployment/UPGRADE.md 的预检。先升级 Controller，再升级 Agent。已经过期的身份须走显式恢复；缺失原密钥不能通过清空数据库或生成替代密钥解决。未知历史快照仍需单独验证。**

下载 `serverfleet_0.9.1_linux_amd64.tar.gz`（Intel/AMD）或 `serverfleet_0.9.1_linux_arm64.tar.gz`（ARM64），均包含 Controller、Agent、Web、部署文档与示例。下载 SHA256SUMS 后执行 `sha256sum --ignore-missing --check SHA256SUMS`；build-manifest.json 记录精确源码和固定工具链。

**本次下载包未做离线发行签名。** SHA256 不代替发行签名，不能直接作为一键安装/自动更新的受信任目录；签名和独立公钥分发按原部署规则执行，不跳过验签。Xray Runtime/Host、受限 Bearer HTTP 适配及真实供应商/root/双机/物理 ARM/硬1C1G验收仍保留已知限制。
